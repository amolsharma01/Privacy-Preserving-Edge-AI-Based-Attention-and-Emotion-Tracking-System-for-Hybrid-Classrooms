# 📌 Overview

The **Privacy-Preserving Edge AI Based Attention and Emotion Tracking System for Hybrid Classrooms** is an advanced AI-powered educational analytics platform designed to monitor and analyze student engagement in real time during online and hybrid learning sessions.

The system leverages:

* 🧠 Artificial Intelligence
* 👁️ Computer Vision
* ⚡ Edge AI
* 🎭 Emotion Recognition
* 📊 Real-Time Analytics

to detect:

* Student attention levels
* Emotional states
* Eye gaze direction
* Head posture
* Blink rate
* Classroom engagement patterns

Unlike traditional cloud-based monitoring systems, this framework performs **AI inference locally on edge devices**, significantly improving:

* 🔒 Privacy Preservation
* ⚡ Low Latency Processing
* 🌐 Reduced Bandwidth Usage
* 🖥️ Real-Time Responsiveness

---

# 🎯 Problem Statement

In modern hybrid and online classrooms, educators face major challenges in understanding whether students are:

* attentive,
* distracted,
* confused,
* fatigued,
* or emotionally disengaged.

Traditional methods such as attendance tracking, quizzes, and verbal interaction fail to provide real-time cognitive engagement insights.

This project addresses these limitations through an intelligent AI-based monitoring framework capable of automatically analyzing student behavior and generating engagement analytics in real time.

# ⚙️ Methodology

The system follows a multi-stage AI pipeline:

## 1️⃣ Video Acquisition

Captures live webcam streams during classroom sessions.

## 2️⃣ Image Preprocessing

Performs:

* Noise Reduction
* Frame Resizing
* Contrast Enhancement
* Brightness Normalization

## 3️⃣ Facial Landmark Detection

Uses MediaPipe & OpenCV to identify:

* Eye regions
* Facial points
* Head orientation

## 4️⃣ Attention Tracking

Analyzes:

* Eye gaze
* Head movement
* Blink frequency
* Face orientation

## 5️⃣ Emotion Recognition

Deep learning models classify student emotions in real time.

## 6️⃣ Dashboard Visualization

Displays:

* Engagement scores
* Emotional trends
* Attention heatmaps
* Classroom reports
